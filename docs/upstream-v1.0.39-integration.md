# 官方 v1.0.39 合并记录

合并日期：2026-10-22。来源：`wxtsky/CodeIsland` 正式标签 `v1.0.39`（`6ba3ad3`）。起点为定制提交 `d34158a`，在 `codex/upstream-v1.0.39-integration-20261022` 分支完成。

## 采用官方实现

- 采用 `RemoteReconnectPolicy`、唤醒和网络恢复触发器、连接令牌及慢速重试；原有远程 Codex 实时事件流继续随 SSH 主连接启停。
- 采用 Codex app-server 的直接父进程身份判定、CLI 与桌面版跳转分流、tmux pane 精确定位及跳转结果检查。定制的本地和远程 Codex 深链接仍优先处理桌面会话。
- 采用 Cursor hook 来源识别与重复事件过滤、pi / Oh My Pi 子代理归属及提示策略、Cursor Task 后台索引。
- 采用官方 SwiftPM native 发布构建流程，包括清除旧产物以及架构和 SDK 校验；补入重新打开应用时显示真实设置窗口的处理。

## 保留定制行为

- Codex 桌面任务数和状态由 hook 与 app-server 实时事件决定，不启用官方按时间轮询状态库的桌面发现路径；保留远程 Codex 事件对账、失败状态监视、会话去重和诊断。
- 普通 SSH 断线将最近卡片标记为离线，移除远程主机才删除卡片。已结束任务按用户时限清理且自动保留至少五条；远程 Codex 卡片携主机身份跨重启恢复。
- 保留 Codex 标题优先、项目登记名称、提示文字清理、远程主机完整编辑、外接屏浮动胶囊和跟随活动屏幕。
- 合并持久化字段时同时保留远程主机信息与官方的子代理父会话 ID。
