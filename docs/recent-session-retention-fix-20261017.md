# 最近任务保留修复（2026-10-17）

任务结束后，运行数下降，最近会话总数保留；按用户设置的空闲保留时间清理。设置 0 表示不按时间清理。重复空闲通知不刷新保留起点。远程连接断开保留卡片并显示未连接，重连复用相同 host/thread 标识。明确归档、移除主机或手动移除仍删除卡片。

## 问题来源

- 定制提交 `012df52`（2026-09-22）引入远程会话对账，活跃列表不再包含的记录会直接 removeSession。
- 定制提交 `5432539`（2026-09-25）将该规则扩展到明确 isActive=false 的记录。
- 定制的远程事件传输退出回调将断线作为空快照传递，触发同一路径。
- 上游 v1.0.38 自带无进程监控时 10 分钟清理、原生线程关闭直接删除和重启仅恢复 30 分钟的行为；不能认为直接换回上游即可满足最近任务保留要求。

## 实现

- 新增 retainEndedSession，释放审批、提问、进程监控和转录跟踪，保留标题、回复和跳转身份。
- 远程同步和 Codex 线程关闭使用保留逻辑；归档保持删除语义。
- 连接中断使用单独回调标记离线，不再发送虚假的空任务列表。
- 清理与启动恢复都遵循用户保留设置；远程 Codex 最近卡片保存 host 标识并可跨重启恢复，恢复时不访问远程 PID 或文件。

## 验证

修复前运行 RecentSessionRetentionTests，3 项测试出现 7 个断言失败；修复后相关 55 项测试通过。新增覆盖完成保留、重复空闲不续期、重连去重、断线保留及 45 分钟记录重启恢复/61 分钟过期的回归测试。完整测试共 2,209 项（5 项按原设计跳过），0 失败；最后补充身份隔离与归档断言后，相关 66 项测试全部通过。发布构建结果以本次交付报告为准。
