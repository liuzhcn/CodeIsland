# 官方 v1.0.38 合并记录

合并日期：2026-10-12。来源：[wxtsky/CodeIsland](https://github.com/wxtsky/CodeIsland)，从 v1.0.35（`b444ae2`）升级到 v1.0.38（`31cf9b5`），共 78 个上游提交。定制分支为 `dev`。

## 官方更新

- **v1.0.36，2026-10-10**：会话列表按状态排序，优先显示等待用户处理的任务；鼠标停留时固定顺序；新增 Compact 密度。审批与提问卡片重新组织按钮和上下文，提问支持只收起而不作答。分组标签、二次确认退出、额度与用量页脚、长内容滚动、文本对比度及减少动态效果支持均有更新。
- **v1.0.36**：收起状态可显示 Claude 套餐额度；新增 MiniMax Code CLI、MiMo Code / 小米 MiMo；修复 Hermes 回合结束、会话清理、标题及远程 hook；Claude Desktop 支持跳转具体 Code 会话。
- **v1.0.36**：修复 Codex hook 的重复 TOML features 表、Interrupt 超时、每轮 Auto Review 与 guardian / review 子会话处理；修复完成卡片的布局循环、刘海遮挡、OpenCode 标题、Qoder 识别及部分安装器误写配置问题。
- **v1.0.37，2026-10-11**：按 transcript originator 区分桌面会话与第三方 app-server 会话；按 app-server 命令和直接父进程识别没有 bundle 环境变量的桌面 hook，避免重复卡片及错误合并子会话。
- **v1.0.38，2026-10-11**：支持 ChatGPT 新版内嵌 CodexCLI 程序路径；按命令和父进程区分桌面 app-server、终端 CLI、第三方 app-server 与非会话进程。

## 与定制功能的取舍

| 功能 | 合并处理 | 原因 |
| --- | --- | --- |
| 新版内嵌 Codex 程序定位 | 采用官方路径常量及候选路径 | 官方已覆盖原定制，删除恢复本地改动时重复添加的路径 |
| 桌面 hook 身份识别 | 采用官方 `codexDesktopTermBundle` | 原定制仅凭程序路径识别；官方结合命令和直接父进程，能避免把共用程序的 CLI 当成桌面会话 |
| Codex 进程角色和 transcript originator 区分 | 采用官方实现 | 官方对第三方 app-server 和非会话命令的处理更完整 |
| 刘海屏收起栏避让 | 采用官方额度预留、右侧宽度测量及位置补偿 | 替换原定制的左右等宽预留，配合官方新的额度芯片 |
| 新会话列表、审批/提问卡片与可访问性 | 采用官方实现 | 使用新密度、排序、按钮和滚动逻辑 |
| 分支名最小显示宽度 | 合入官方布局指标 | 保留定制标题行，同时避免分支只剩图标和省略号 |
| Codex 实时状态和任务计数 | 保留定制事件驱动 | 官方仍通过 rollout / SQLite 发现桌面会话；定制要求实时服务通知与 hook 驱动状态，文本读取只补充内容 |
| hook 元信息缺失时的身份补全、历史卡片迁移 | 保留定制补充处理 | 官方桥接修复处理新事件；已有卡片和后续缺失元信息仍需兼容处理 |
| Codex 会话标题优先、项目标签和提示文本清理 | 保留定制 | 官方标题行及通用 wrapper 清理没有覆盖 Codex 项目登记信息与浏览器上下文清理 |
| 本地及远程 Codex 精确跳转 | 保留定制 | 官方新增 Claude Desktop 跳转不等于 Codex thread / hostId 跳转 |
| 外接屏浮动栏、尺寸随内容适配、零会话计数 | 保留定制 | 官方刘海避让没有替代无刘海显示器的浮动布局 |
| 远程实时连接、重连、去重与 SSH 主机编辑 | 保留定制 | 上游没有等价覆盖 |
| Codex 连接失败提示、握手超时、远程每轮审批模式读取 | 恢复原有未提交改动 | 保留此前工作，不混入上游合并提交 |
